## 📌 Sobre o Projeto

Este projeto consiste na criação de um banco de dados relacional que modela as principais entidades envolvidas na **Copa do Mundo FIFA**, como seleções, jogadores, partidas, grupos, estádios e resultados.

O objetivo é aplicar os conceitos estudados em sala de aula, como:

- Modelagem Entidade-Relacionamento (ER)
- Normalização de tabelas
- Criação e manipulação de banco de dados com SQL
- Relacionamentos entre entidades (1:N, N:N)

## 🗃️ Estrutura do Banco de Dados

O banco de dados contempla as seguintes entidades principais:

- **Seleção** — países participantes da copa
- **Jogador** — atletas vinculados a cada seleção
- **Pais** — de onde os jogadores, arbitros e tecnicos vieram
- **Partida** — confrontos entre seleções, com data, local e resultado
- **Estádio** — locais onde as partidas foram realizadas
- **fase** — classificação do tipo de partida
